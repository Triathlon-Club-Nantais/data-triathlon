# Navigation couche 2 : espace Encadrement (#1297) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sortir Jeunes et la validation des crédits bénévoles du back-office vers un espace « Encadrement » ouvert par `can_supervise`, avec sa propre garde et l'atterrissage SSO sur le premier espace ouvert.

**Architecture:** Le catalogue backend classe chaque pouvoir (`kind`) ; `administers()` et un nouveau `supervises()` en dérivent `can_administer` et `can_supervise` dans `GET /auth/me`. Côté front, la garde de `app/admin/layout.tsx` est extraite en une fonction partagée réutilisée par `app/encadrement/layout.tsx`, puis les écrans déménagent sous `/encadrement`.

**Tech Stack:** FastAPI, Pydantic v2, pytest ; Next.js 16 App Router, TypeScript strict, Vitest + Testing Library.

**Spec:** `docs/superpowers/specs/2026-10-10-navigation-espaces-design.md` (sections « Les trois espaces », « Routes, gardes, configuration », couche 2).

## Global Constraints

- `/admin/jeunes/**` devient `/encadrement/jeunes/**`, `/admin/benevolat` devient `/encadrement/benevolat`. Aucune redirection depuis les anciennes URL.
- `/encadrement` redirige vers le premier écran ouvert au compte.
- `app/encadrement/layout.tsx` applique la garde de `app/admin/layout.tsx` (session, pannes passantes, refus rendu sur place) sur `can_supervise`. La logique commune est extraite dans une fonction partagée.
- Le callback SSO mène au premier espace ouvert : Back-office (`/admin`), sinon Encadrement (`/encadrement`), sinon Accueil (`/dashboard`). La destination reste fixée par le code, aucun paramètre d'entrée (FR-026).
- `permissions.administers()` exclut les pouvoirs d'encadrement (`jeunes:read`, `jeunes:write`, `athletes:volunteer_validate`) ; `supervises()` alimente `can_supervise`. Champ ajouté à `/auth/me`, aucun champ existant ne change (Principe IV).
- Les routes d'API (`/api/v1/admin/...`) ne changent pas.
- Langue : UI et commentaires métier en français, identifiants et tests en anglais pour le code neuf ; les fichiers existants entièrement en français gardent leur style.
- Jamais de tiret (—, –, -) pour ponctuer une phrase, dans le code ni les commentaires.
- Commentaires seulement si nécessaires, concis.
- Avant chaque commit front : `git checkout frontend/.vitest/json/output.json` (les tests le réécrivent).
- Commits : Conventional Commits, suffixe `(Refs #1297)`, aucun trailer `Co-Authored-By`.

## Rulings du plan

- Le pouvoir porte un `kind: Literal["administration", "supervision", "consultation"]` qui remplace le booléen `consultation` : deux booléens permettraient une combinaison absurde.
- `athletes:volunteer_validate` passe en `supervision` : sa page passe en Encadrement (spec). Son compteur sort donc du total « Back-office · N ».
- Les composants restent sous `components/admin/jeunes/` : seules les routes déménagent (diff minimal, aucune valeur à renommer le dossier).
- Les entrées d'Encadrement perdent leur `helpAnchor` : le guide vit sous `/admin/guide`, fermé à un encadrant sans pouvoir d'administration. Suivi à ouvrir si un guide d'encadrement est voulu.
- `AdminIndex` filtre sur `space === "admin"` au lieu du préfixe `/admin/`.

```tsx
import { redirect } from "next/navigation";
import type { ReactNode } from "react";
import { PageShell } from "@/components/layout/PageShell";
import { PageHeader } from "@/components/layout/PageHeader";
import { ApiError } from "@/lib/api/client";
import { apiServer } from "@/lib/api/server";
import type { SessionUser } from "@/lib/types";

export async function spaceRefusal(
  title: string,
  allows: (session: SessionUser) => boolean,
  refusal: ReactNode,
): Promise<ReactNode | null> {
  const [session, methodes] = await Promise.all([
    apiServer.getSession().catch(panne("session")),
    apiServer.listAuthMethods().catch(panne("méthodes de connexion")),
  ]);
  if (session === null && methodes !== INDISPONIBLE && methodes.length > 0) {
    redirect("/login");
  }
  if (session !== null && session !== INDISPONIBLE && !allows(session)) {
    return (
      <PageShell>
        <div className="space-y-6">
          <PageHeader title={title} />
          {refusal}
        </div>
      </PageShell>
    );
  }
  return null;
}
```
