# Archive

Designs (`specs/`) et plans (`plans/`) de features **livrées**, déplacés hors du
chemin de découverte de `brainstorming`/`writing-plans` : valeur historique
uniquement, plus consultés lors d'un cycle de planification actif.

Critères de migration ici, et condition de retour en arrière si un fichier
redevient cité ou révisé : `docs/WORKFLOW-IA.md`, section « Archivage des
designs de features livrées ».

Ne contient **jamais** de sondage, d'audit ni de rapport de terrain — ceux-là
restent sous `docs/superpowers/specs/` indéfiniment, quel que soit leur âge.
